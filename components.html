What does the expression a, b = b, a + b accomplish on each loop iteration?

Python evaluates the right-hand side completely before assigning. Both b and a + b are computed using the current values, then assigned in one step — so a steps forward to the old b, and b steps forward to their sum, simultaneously. No temporary variable needed.
